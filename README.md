# 🛠️ Ferremas
 
 **FERREMAS** es una distribuidora de productos de ferretería y construcción con más de 40 años de experiencia en el rubro, contando actualmente con siete sucursales distribuidas entre la Región Metropolitana y otras regiones del país. A lo largo de su trayectoria, ha brindado soluciones a empresas y clientes particulares mediante la venta presencial de herramientas, materiales eléctricos, pinturas y artículos de seguridad, trabajando con marcas reconocidas como Bosch, Makita, Stanley y Sika.

 ## ⚙️ Tecnologías Utilizadas
 
 - **Frontend**:  React (con TypeScript), HTML5, CSS3 (interfaz para el usuario. Permite navegar por catálogos, gestionar pedidos, inventario, etc. Se comunica con el backend vía APIs REST.)
 - **Backend**: TypeScript, Railway, Node.js (Procesa las solicitudes, valida datos, aplica reglas del negocio y conecta la vista con la base de datos).
 - **Despliegue**: PHP, MySQL (Gestiona la base de datos (usuarios, productos, pedidos), asegura la integridad de los datos y optimiza las consultas).
 
 ---
 ## 🧪 Entornos de Desarrollo

 - Implementación del sistema en módulos separados para frontend, backend y base de datos.
 - Desarrollo del frontend con React, HTML5 y CSS3, probando en entornos locales de navegador.
 - Backend desarrollado con TypeScript y desplegado mediante Railway, facilitando pruebas continuas y despliegues rápidos.
 - Uso de PHP y MySQL para la capa de datos, con pruebas de consultas y lógica directamente sobre la base de datos.
 - Comunicación entre capas mediante APIs REST, permitiendo testeo modular e integración progresiva.
 
---
 ## 📌 Funcionalidades Clave
 
 - Inicio de sesión para clientes, administradores, vendedores, bodegueros y contadores
 - Registro de clientes con correo para recibir noticias y descuentos por compras mayores a 4 artículos
 - Visualización de productos y compras mediante carrito virtual
 - Opciones de retiro en tienda o despacho a domicilio
 - Múltiples métodos de pago: débito, crédito, transferencia
 - Gestión de pedidos según rol: aprobación, preparación y despacho
 - Confirmación de pagos y registro de entregas por parte del contador
 - Generación de informes y balances por administrador
